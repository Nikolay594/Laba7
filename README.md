### Домашняя работа (Условие)
17. Пароль от Wi-Fi

В кафе Wi-Fi пароль обновляется каждый час на основе двух чисел (A и B). Новый пароль активен, если ровно одно из этих чисел четное. Запишите условие активности пароля.


### 1. Алгоритм

1. Начать программу.  
2. Объявить переменные `A` и `B` типа `int`.  
3. Ввести с клавиатуры значения `A` и `B`.  
4. Проверить условие:  
  (A % 2 == 0 && B % 2 != 0) || (A % 2 != 0 && B % 2 == 0)
5. Если условие истинно → вывести `YES`.  
6. Иначе → вывести `NO`.  
7. Завершить программу.

# 2. Реализация программы
Программа реализована на C

Для ввода значений используется функция scanf()

Для проверки условия используется:

"&&" - логическое и;

"!=" и "==" - операторы сравнения;

If и else - условный оператор

# 3. Результаты работы программы
Программа проверяет если только одно из чисел чётное, то пароль активен иначе неактивен 

Контрольный пример: (2;1) --> Yes

Контрольный пример: (2;2) --> No
