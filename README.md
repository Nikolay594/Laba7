# HomeWork Laba7
### Домашняя работа (Условие)
17.
Написать программу, которая выводит название введенного знака
препинания.


### 1. Алгоритм

1. Начать программу.  
2. Объявить переменную `с` типа `char`.  
3. Ввести с клавиатуры знак препинания для `c`.  
4. Проверить введённый символ с помощью оператора `switch`.
5. Если символ совпадает с одним из знаков препинания, вывести его название.
6. Если символ не найден, вывести сообщение `Неизвестный знак препинания`.
7. Завершить программу.

# 2. Реализация программы
Программа реализована на C.

Для ввода символа используется функция `scanf()`.

Для проверки введённого символа используется оператор `switch`.

`case` — задаёт варианты символов для проверки.

`break` — завершает выполнение варианта.

`default` — выполняется, если введённый символ не совпадает ни с одним из перечисленных.

# 3. Результаты работы программы
Программа определяет введённый знак препинания и выводит его название.

Контрольный пример: `.` --> Точка

Контрольный пример: `,` --> Запятая

Контрольный пример: `?` --> Вопросительный знак

Контрольный пример: `!` --> Восклицательный знак
